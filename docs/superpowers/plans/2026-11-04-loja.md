# UI 2: Loja — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trocar a Loja do mockup G7a por uma loja em tela cheia com pacotes em destaque, gamepasses, giros por tipo (carrossel estilo CS:GO, efeitos no pago) e pacotes de Golden Ember — tudo simulado.

**Architecture:** Dados de mockup no `MockStore` (catálogo); regras puras de sorteio, contadores e grades em `src/shared/UIFlow` (Lune). A UI fica em `src/client/Menu/Shop/` (Vide), montada pelo `MenuShell` quando o painel `"shop"` abre em tela cheia. Placeholders desenhados por código onde a arte ainda não chegou.

**Tech Stack:** Luau `--!strict`, Vide, TweenService/RunService, Lune, MCP do Studio.

**Spec:** `docs/superpowers/specs/2026-11-04-loja-design.md` (ler inteiro). Preview: `docs/game-design/propostas/loja-v1/preview.html` (layout; as raridades valem as do spec, 6 níveis).

## Global Constraints

- Branch `loja` a partir da `main`. Commits pt-BR com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Sem push.
- Mockup: nenhum evento de rede novo, nenhum atributo escrito, nenhum `MarketplaceService`; o saldo (`Currency`) nunca muda.
- Raridades = 6 tiers na ordem `wood, stone, gold, diamond, amethyst, reidite` (Comum, Incomum, Raro, Épico, Mítico, Lendário); cor = `Theme.tier[id]`, nome = `Strings.get(Defs.Tiers[id].rarityKey)`.
- Chances: normal `{60, 25, 10, 4, 0.9, 0.1}`, pago `{30, 25, 20, 15, 7, 3}`; vitrine `{30, 25, 18, 13, 9, 5}`.
- Preços dos giros: normal 1/3/10 = 100/280/850 Golden Ember; pago 1/3/10 = 49/129/399 Robux. Comprar com Golden Ember exige `saldo >= preço` (não desconta).
- Tipos de giro (ordem): `body` Skins, `accessory` Acessórios, `bag` Mochila, `book` Livro, `crate` Caixa.
- Confete do prêmio: 20/30/50/80/110/140 (comum → lendário); giro normal só a partir de Raro, com 20.
- Carrossel: ocioso 40 px/s; giro 5,2 s com desaceleração forte (TweenService Quint Out); prêmio pode parar até ±35% de um quadradinho fora do centro.
- Design system rústico + artes já enviadas (`UiImages.PLANK`, `BUTTON_EMBER`, `COIN`); alvos ≥ 44 px; compacto = largura < 900 ou altura < 500.
- Textos em `ptBR.luau` (bloco `shop.*`). `bash scripts/check.sh` verde ao fim de cada task. Rojo duplica arquivo novo no place: conferir antes de testar.

## Review Focus

1. **Comprar e girar rápido / fechar no meio do giro:** cliques repetidos em GIRAR durante a animação não gastam giros a mais nem empilham animações; fechar a tela (ou sair da loja/menu) no meio do giro não deixa tween, faísca ou loop rodando, e o contador continua certo. → SpinRules (Task 1) + SpinScreen (Task 6), conferido no Studio.
2. **Celular (568×320 … 844×390):** loja em tela cheia sem a coluna; grades com menos colunas; a tela do giro empilha os lados sem cortar GIRAR. → ShopLayout (Task 2) + Studio com `Setting_ui_scale` 2.
3. **Saldo insuficiente / saldo muda com a loja aberta:** botão de Golden Ember apagado com "faltam N" e reativa quando o saldo sobe. → SpinRules.canAfford (Task 1) + Task 6.
4. **Tipo sem item de uma raridade sorteada:** o sorteio nunca devolve nil (cai na raridade mais próxima abaixo). → SpinRules (Task 1).
5. **Abrir a loja pelo "+" e pelas abas:** o "+" abre a loja já em Golden Ember; aba ativa acompanha a rolagem; voltar ao menu restaura coluna/boneco. → Tasks 3–4, Studio.

  - `SPIN_PRICES = { normal = { {qty=1,price=100},{qty=3,price=280},{qty=10,price=850} }, paid = { {qty=1,price=49},{qty=3,price=129},{qty=10,price=399} } }`

  - `export type Pass = { id: string, nameKey: string, descKey: string, robux: number, kitId: string? }` — `PASSES`: os 4 kits (`robux = KIT_ROBUX[kit].forever`, `kitId`) + `vip` (149, sem kitId).
- Produces (`SpinRules`, puro):
  - `pickIndex(weights: { number }, r: number): number` (o antigo `MockStore.roll`, mesmo comportamento)
  - `pickItem(items: { SpinItem }, rarity: number, r: number): SpinItem` — sorteia entre os itens da raridade; sem nenhum, desce de raridade até achar
  - `export type Counts = { [string]: { normal: number, paid: number } }`; `newCounts(): Counts`; `addSpins(c, typeId, kind: "normal"|"paid", qty): Counts`; `canSpin(c, typeId, kind): boolean`; `useSpin(c, typeId, kind): Counts` (sem giro: devolve igual) — imutáveis
  - `canAfford(balance: number, price: number): boolean` (NaN/inf = falso, como o `KitRules.canBuy`)
  - `confettiFor(rarity: number, paid: boolean): number` (valores da Global Constraints; normal abaixo de Raro = 0)
