# F5 Telas — Plano de implementação

> **Para o implementador (Cline):** leia primeiro "Como trabalhar neste plano". Execute as tarefas **em ordem**, marcando os checkboxes. Nas **🛑 PARADAS**, pare e avise o Elizeu: quem valida no Studio é o Claude (outra sessão); só continue depois do "pode seguir".

**Goal:** Fluxo completo do jogo — carregamento → menu → jogar → morte → menu/jogar de novo — com configurações e kits iniciais, usando telas provisórias feitas como **moldes** (instâncias em arquivo ligadas ao código por nomes), para o Elizeu trocar o visual depois sem mexer em código.

**Architecture:** Servidor: o personagem só nasce a pedido (`CharacterAutoLoads = false`), com kit opcional pago com os pontos da última vida; uma função única de morte (fim de vida da F4 + zera inventário + tira o personagem + manda o resumo); quem está no menu "assiste" um jogador aleatório (atributo + foco de streaming). Cliente: um estado de tela (`loading/menu/playing/dead`) decide o que aparece; cada tela é um molde de `ReplicatedStorage.UITemplates` clonado e ligado por um binder (acha elementos por nome, aplica textos por `TextKey`, dá feedback aos botões, aplica `UIScale`). A lógica pura (transições, kits, contagem pontos→moeda, formatação das configurações) é testada no Lune.

**Tech Stack:** Luau `--!strict`, Rojo 7.7.1 (inclusive `*.model.json`), Vide 0.4.1, Blink 0.18.9, Lune.

**Spec:** `docs/superpowers/specs/2026-10-29-f5-telas-design.md` (leia inteiro antes da Tarefa 1). Contexto: `docs/guia/dados.md` (F4), `docs/guia/hud.md`, `docs/game-design/identidade-visual.md`.

## Global Constraints

- Estados de tela: `"loading" | "menu" | "playing" | "dead"`; Configurações é janela por cima (abre em `menu` e `playing`).
- Atributos novos no **Player** (`StatNames`): `DataReady` (bool), `KitPoints` (number), `SpectateTarget` (number, UserId; 0 = ninguém).
- `Players.CharacterAutoLoads = false` (também no `default.project.json`; em place existente o Claude/Elizeu marca à mão).
- Botão "Reset Character" do Roblox desligado (`StarterGui:SetCore("ResetButtonCallback", false)`, com tentativas como no `CoreGuiController`).
- Câmera do menu: troca de alvo a cada **8 s**; sem alvo, gira sobre o centro do mapa (0, 0, 0).
- Animação pontos→Golden Ember: **2 s**; mundo cinza: `ColorCorrectionEffect.Saturation` até **−1 em 1 s**, volta a 0 ao nascer.
- Kits (`Defs/Kits.luau`), valores provisórios exatos:
  - `kit_starter` order 1, price 1000: berry 8, wood 20
  - `kit_explorer` order 2, price 2000: berry 16, wood 40, stone 20, wood_pickaxe 1
  - `kit_survivor` order 3, price 4000: berry 20, wood 140, stone 80, stone_pickaxe 1, leather_bag 1
  - `kit_veteran` order 4, price 8000: berry 30, wood 200, stone 150, gold 20, gold_pickaxe 1, leather_bag 1
- Textos novos em `Strings/ptBR.luau` (chaves exatas; textos curtos em pt-BR à sua escolha onde não indicado): `loading.title` = "Ember Wilds", `loading.status` = "Carregando…", `menu.play` = "Jogar", `menu.settings` = "Configurações", `menu.balance` = "{amount} Golden Ember", `menu.kits` = "Kit inicial", `death.title` = "Você morreu", `death.cause` = "Causa: {cause}", `death.days` = "Dias vividos: {days}", `death.points` = "{points} pts", `death.currency` = "+{amount} Golden Ember", `death.playAgain` = "Jogar de novo", `death.menu` = "Menu", `death.cause.dev` = "Teste", `death.cause.unknown` = "Desconhecida", `kit.<id>` (nome de cada kit), `kit.price` = "{price} pts", `kit.points` = "Pontos para kit: {points}", `settings.title` = "Configurações", `settings.close` = "Fechar", `setting.quality.auto|low|medium|high` (nomes das opções), `setting.on` = "Ligado", `setting.off` = "Desligado".
