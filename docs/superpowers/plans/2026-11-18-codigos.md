# Códigos de resgate — plano

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline, escolhido pelo Elizeu).

**Goal:** jogadores resgatam no menu códigos definidos em `Shop/Codes.luau`, uma vez cada.
**Architecture:** regra pura `Shop/CodeRules` (testada) + dados `Shop/Codes`; servidor `CodeService` (Net `RequestCode`/`CodeResult`); cliente `Menu/CodePanel` (botão + janela).
**Spec:** `docs/superpowers/specs/2026-11-18-codigos-design.md`

## Global Constraints
- `bash scripts/check.sh` → `N passed, 0 failed`. Server Authority. Textos em `Strings/ptBR.luau`. Python com `newline=''`.

## Review Focus
1. Código digitado com espaços/minúsculas → mesmo código (`CodeRules.normalize`).
2. Tentativas em rajada → só uma a cada 2 s (Throttle), resposta "aguarde".
3. Resgate durante a partida (cliente modificado) → recusado no servidor (`LifeService.lifeKey`).

### Task 1: CodeRules + Codes + ShopData.Codes
- Create `src/shared/Shop/CodeRules.luau`: `normalize(text): string` (tira espaços, maiúsculas); `find(list, code): CodeDef?`; `check(def: CodeDef?, used: {[string]: boolean}, now): Refusal?` com `Refusal = "unknown" | "notYet" | "expired" | "used"`; `validate(list, defs): {string}`.
- Create `src/shared/Shop/Codes.luau` (lista; 1 código de teste `TESTE` com `endsAt` próximo, marcado para tirar).
- `ShopData`: `Codes: { [string]: boolean }` em `empty()`; `ShopData.useCode(d, code)`.
- Tests `tests/coderules.spec.luau`: normalize ("  lan camento " → "LANCAMENTO"), check (unknown, notYet, expired no fim exato, used, ok), validate (código inválido, repetido, sem prêmio, prêmio inválido, data ruim, fim antes do começo) e "o arquivo real valida".

### Task 2: CodeService + rede + boot
- Blink: `RequestCode { Code: string(1..32) }`, `CodeResult { Ok: boolean, Reason: string(1..16)?, Text: string(0..200)? }`.
- `ShopService.giveAll(player, rewards, reason): boolean` (grant de todos, publica e salva uma vez).
- `CodeService`: throttle 2 s ("wait"), `LifeService.lifeKey(player) ~= nil` → "inGame", `CodeRules.check` contra `Shop.Codes`, entrega, `useCode`, `Text` = prêmios por `RewardView`-equivalente no servidor (lista de `RewardBadge`/texto curto). Validação de `Codes` no boot (erro com a lista).

### Task 3: CodePanel no menu
- Botão embaixo do calendário (`layout().calendarY + calendarSize + CALENDAR_GAP`), mesma visibilidade do calendário; janela com TextBox, Resgatar (Rustic ember), Fechar, linha de resposta; conferir no Studio (PC e emulador).
