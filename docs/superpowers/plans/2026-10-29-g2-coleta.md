# G2 Coleta — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (decidido pelo Elizeu: eu implemento aqui). Passos com caixinha (`- [ ]`).

**Objetivo:** bater em árvore, rocha, ouro e arbusto coleta recursos (rendimento por picareta), com reserva que acaba e regenera, frutinhas visíveis no arbusto, "poing" + lasquinhas + som, pontos e ranking reais.

**Arquitetura:** regras puras em `src/shared/Gather/` (Lune); `ResourceService` guarda a reserva de cada recurso montado (grade espacial + regeneração); `GatherService` faz o golpe; `ScoreService` é dono de Score/Rank; o cliente só mostra (efeitos via Blink, frutinhas via atributo).

**Stack:** Luau `--!strict`, Rojo, Blink, Vide, Lune. Verificar: `bash scripts/check.sh`.

**Spec:** `docs/superpowers/specs/2026-10-29-g2-coleta-design.md`

## Regras globais

- pt-BR em comentários, textos e commits; commit por tarefa; sem push; `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Conteúdo é dado: nada de `if resourceId == "tree"`.
- Server Authority: servidor decide alvo, rendimento e reserva.
- Atributos e tags por `StatNames`.

## Foco de revisão

1. Inventário cheio: nada sai da reserva, sem pontos, aviso "Inventário cheio".
2. Cabe só parte: a reserva e os pontos descontam só o que entrou.
3. Recurso vazio: aviso "Este recurso acabou", nada coletado, e o aviso não se repete mais de 1 vez a cada 2 s.
4. Comida na mão, jogador no menu ou morto: não coleta.
5. 1.600 recursos: o golpe só olha a grade perto do ponto (nunca varre todos).

### Tarefa 4: O golpe (GatherService)

**Arquivos:** criar `src/server/Services/GatherService.luau`; modificar `Strings/ptBR.luau`.

- Laço a cada 0,05 s: para cada jogador vivo com `Using == true`, sem comida na mão e com `now >= nextHit[player]`: `nextHit = now + HIT_INTERVAL`; ponto do golpe = raiz + LookVector (XZ) × `HIT_REACH`; `pickTarget(ResourceService.near(ponto, HIT_RADIUS + 5), ...)`; sem alvo = nada.
- Ferramenta = `Defs.Items[Equipped]`. `yield == nil` → aviso `gather.needTool` com o item de `requiredPickaxe`. Reserva 0 → aviso `gather.empty`. Senão `n = min(yield, amount)`, `sobra = InventoryService.give(item, n)`, `dado = n - sobra`; `dado == 0` → aviso `gather.full`; senão `ResourceService.take(entry, dado)`, `ScoreService.add(dado * points)`, `StatsService.add(player, "resources_gathered", dado, item)`.
- Todo golpe com alvo manda `ResourceHit` (FireList) para jogadores a até 100 studs (também quando vazio/sem ferramenta: o recurso balança igual).
- Avisos: no máximo 1 da mesma chave a cada 2 s por jogador.
- Strings: `gather.empty` "Este recurso acabou", `gather.needTool` "Precisa de {item}", `gather.full` "Inventário cheio".
