# Missões (partida, diárias, semanais, conquistas) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tela de Missões com quatro abas (Partida = chrono quests da vida; Diárias; Semanais; Conquistas), regras no servidor, progresso salvo no perfil e prêmios por RESGATAR.

**Architecture:** Conteúdo em `Defs` (Quests, Missions, Achievements). Regras puras e testadas em `src/shared/Missions/`. Dois serviços: `QuestService` (chrono quests, só em memória, por vida) e `MissionService` (diárias, semanais e conquistas, no perfil). O progresso das diárias, semanais e conquistas vem das **estatísticas** que já existem (`StatsService`): a missão guarda o valor da estatística quando foi sorteada (base) e o progresso é `atual − base`. O cliente recebe um retrato completo (`Net.MissionsData`) só do dono e pede o resgate (`Net.ClaimMission`). A tela é um overlay como as Configurações (`SettingsScreen`), aberto pelo HUD e pelo menu.

**Tech Stack:** Luau `--!strict`, Rojo, Blink (`net/game.blink`), Vide (UI), ProfileStore (via `DataService`), Lune (testes `tests/*.spec.luau`), Python + Pillow para recorte das artes.

**Spec:** `docs/superpowers/specs/2026-11-12-missoes-design.md` (números das chrono quests: `docs/game-design/quests-starve.md`; artes: `docs/game-design/assets-ui-missoes.md`).

## Global Constraints

- Verificação: `bash scripts/check.sh` (Blink, StyLua, selene, Rojo build, luau-lsp, Lune) tem de passar no fim de cada tarefa.
- Projeto: graphify antes de explorar código (`& (Get-Content graphify-out\.graphify_python) -m graphify query "<pergunta>"` no PowerShell; o `graphify` não está no PATH); depois de mudar código, `& (Get-Content graphify-out\.graphify_python) -m graphify update .`.
- Conteúdo é dado: nenhum código conhece missão, quest ou conquista pelo id (só `Defs`).
- Todo texto visível vem de `Strings` (`src/shared/Strings/ptBR.luau`); toda cor de `Theme`/`Palette.rustic`.
- Tudo é decidido no servidor; estado vai só para o dono; o cliente só pede resgate.
- Golden Ember das missões **não** passa pelo teto de 300/h: entrega por `ShopService.give` (recompensas `ember`, `spins`, `kit`, `kitOnce`, `cosmetic`).
- Modo criativo (`CreativeService.isOn`): missões desligadas (sem progresso, sem prêmio); a tela mostra "Missões desligadas no modo criativo".
- 1 dia de jogo = `DataConfig.DAY_CYCLE_SECONDS` (480 s). Viradas: diária à meia-noite de Brasília (`RankRules.dayIndex`), semanal domingo 23:59:59 de Brasília (`RankRules.weekIndex`/`weekEnd`).
- `SCHEMA_VERSION` não sobe: o campo novo do perfil entra pelo `ProfileTemplate` (Reconcile) e é saneado na leitura, como `Ranking`.
- Atributos replicados: nada de missão em atributo (limite ~1 KB por instância; ver memória do projeto). Tudo por `Net`.
- Mensagens de commit em pt-BR, terminando com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Sem push.

## Review Focus

1. **Virada do dia/semana com o jogador online:** à meia-noite as diárias trocam sozinhas, as não resgatadas somem e o retrato novo chega sem reabrir a tela. → teste `period rolls over at midnight` (Task 3) + passo de Studio (Task 9).
2. **Resgate repetido (spam ou dois pedidos juntos):** o prêmio sai uma vez só. → teste `claim twice pays once` (Tasks 3 e 4).
3. **Inventário cheio ao resgatar uma chrono quest:** o resgate é recusado com aviso "Inventário cheio" e a quest continua pronta. → passo no `QuestService` (Task 6) + teste `chrono claim needs space` na regra (Task 4).
4. **Perfil velho ou quebrado** (sem `Missions`, tipos errados, id de missão que saiu de `Defs`, base maior que o valor atual): vira estado válido sem erro; progresso nunca negativo. → teste `sanitize drops unknown ids and bad fields` (Task 3).
5. **Morrer entre "pronta" e "resgatar":** chrono quest pronta some com a vida; diária/semanal/conquista prontas continuam no perfil e podem ser resgatadas no menu. → teste `chrono state ends with the life` (Task 4) + passo de Studio (Task 9).
