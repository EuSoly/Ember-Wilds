# F6 Mundo — Plano de implementação

> **Para o implementador (Cline):** leia "Como trabalhar neste plano". Tarefas **em ordem**, marcando os checkboxes. Nas **🛑 PARADAS**, pare e avise o Elizeu (quem valida no Studio é o Claude); só continue depois do "pode seguir".

**Goal:** Mapa de verdade no layout do Starve.io (floresta jogável no canto inferior esquerdo), desenhado à mão pelo Elizeu no Studio, com recursos espalhados por zonas de forma determinística, recursos sólidos (copas transparentes por cima do jogador), água que deixa lento e tira o fôlego (bolha de ar), borda trancada, minimapa do mapa inteiro e iluminação de dia e noite.

**Architecture:** Toda a geometria e o espalhamento são **puros** (`src/shared/World/`, formas como números: caixa girada em Y e disco) e testados no Lune. No servidor, o `MapService` lê `Workspace.Map` (feito no Studio), converte as peças em formas, espalha os recursos com semente fixa e monta os modelos (código) em `Workspace.Resources`; sem mapa, cai no chão de teste. A lentidão na água roda na simulação (dos dois lados, como o `FacingSim`); o oxigênio é um atributo do Player calculado no servidor. Iluminação, bolha de ar, copas transparentes, aviso de borda e minimapa são do cliente.

**Tech Stack:** Luau `--!strict`, Rojo 7.7.1, Vide 0.4.1, Lune.

**Spec:** `docs/superpowers/specs/2026-10-29-f6-mundo-design.md` (leia inteiro antes da Tarefa 1). Contexto: `docs/game-design/catalogo-e-roadmap.md` ("Mapa e biomas"), `docs/game-design/identidade-visual.md` (noite, fogo, escala, formas por tier), `docs/guia/arquitetura.md`.

- Atributos/tags novos (`StatNames`): `InWater` (Player, bool), `Oxygen` (Player, 0–100), `ResourceId` (atributo), `ZoneType` (atributo), `ResourceTag = "Resource"`, `OccluderTag = "Occluder"`.

- Luz da fogueira: `PointLight` cor `#FFA43A`, `Range = 18`, `Shadows = false`, leve tremulação de brilho.

**Interfaces:**
- Types: `ResourceDef = { id, nameKey, radius: number, collisionRadius: number, variants: number }`; `ResourceZoneDef = { id, nameKey, densities: { [string]: number } }`; `DefsTables` ganha `Resources` e `ResourceZones`. Validação (se presentes): ids/nameKey; `radius > 0`, `0 < collisionRadius <= radius`, `variants` inteiro ≥ 1; zona: `densities` não vazio, cada chave existe em `Resources`, valor ≥ 0.
- `Shapes` (puro):
  ```luau
  export type Shape = { kind: "box", cx: number, cz: number, sx: number, sz: number, yaw: number } | { kind: "disc", cx: number, cz: number, r: number }
  Shapes.contains(shape: Shape, x: number, z: number): boolean
  Shapes.area(shape: Shape): number
  Shapes.bounds(shape: Shape): (number, number, number, number) -- minX, minZ, maxX, maxZ (caixa que envolve)
  Shapes.anyContains(shapes: { Shape }, x: number, z: number): boolean
  ```
  `yaw` em radianos (rotação em Y); `sx/sz` = tamanho total.
- `Scatter` (puro):
  ```luau
  export type Zone = { shape: Shapes.Shape, densities: { [string]: number } }
  export type Placement = { resourceId: string, x: number, z: number, variant: number, yaw: number }
  Scatter.generate(params: {
  	zones: { Zone },
  	blockers: { Shapes.Shape }, -- água + NoSpawn
  	fixed: { Placement }, -- recursos colocados à mão (entram primeiro e ocupam espaço)
  	resources: { [string]: ResourceDef },
  	seed: number,
  	minPassage: number,
  	maxAttemptsPerItem: number?, -- padrão 30
  }): { Placement } -- só os gerados (não repete os fixos)
  ```
  Regras: para cada zona em ordem, `Random.new(seed + índiceDaZona)` (o `Random` do Luau existe no Lune); alvo de cada recurso = `floor(área × densidade / 10000)`; sorteia ponto dentro dos `bounds` da forma; aceita se está na forma, fora de todo bloqueador (considerando o `radius` do recurso: o centro tem que estar a pelo menos `radius` da borda do bloqueador — pode aproximar testando o centro e 4 pontos a `radius` de distância), e se para **todo** recurso já colocado a distância entre centros ≥ `max(radiusA, radiusB)` **e** ≥ `collisionRadiusA + collisionRadiusB + minPassage`. Use uma grade espacial (células de ~16 studs) para não comparar com todos. `variant` = inteiro em `[1, variants]`, `yaw` em `[0, 2π)`, ambos do mesmo `Random`. Desiste de um item depois de `maxAttemptsPerItem` falhas seguidas.
- `WorldConfig`, `StatNames`, `Strings`: valores da seção Global Constraints.
