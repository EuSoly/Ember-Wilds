### Tarefa 1 (Sonnet): Dados e regras do mockup

**Arquivos:** criar `src/shared/UIFlow/MockStore.luau`; `src/shared/Strings/ptBR.luau`; teste `tests/mockstore.spec.luau`.

**Produz:**
```lua
MockStore.PACKS: { { amount: number, robux: number, tag: string? } }
--   300/80, 600/150, 2600/600 "popular", 7000/1500 "off30", 20000/3500 "best"
MockStore.SPINS: { { id: string, nameKey: string, price: number, kind: "skin" | "custom",
                     odds: { { nameKey: string, chance: number } } } }
--   skin: inicial 100, dourado 300, dragão 600; custom: inicial 50, dourado 150, dragão 300 (preços da referência)
MockStore.KIT: { items: { string }, offers: { { hours: number, price: number } } }  -- livro + mochila; 1 h 300, 24 h 600
MockStore.CATEGORIES: { { id: string, nameKey: string, items: { { id: string, nameKey: string } } } }
--   skins (vazio: usa as skins de corpo reais), accessories, bag, book, crate (3–4 itens falsos cada)
MockStore.RANKING: { { name: string, points: number } }  -- 10 linhas
MockStore.PROFILE: { level: number, xp: number, xpMax: number, stats: { { nameKey: string, value: number } } }
MockStore.TUTORIAL: { string }  -- chaves de texto dos passos
MockStore.roll(odds: { { chance: number } }, r: number): number  -- índice sorteado com r em [0,1)
```
